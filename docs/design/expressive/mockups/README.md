# Expressive redesign mockups

Open each file in a browser (needs internet once for the Roboto Flex web font). Each page may show alternatives; the approved choice is named below.

- `01-home.html`: Home: three directions shown; CHOSEN = B Dusk Expressive (the right-hand phone)
- `02-onboarding.html`: Onboarding: CHOSEN = option 2, paged story (right-hand phones)
- `03-themes-and-appearance.html`: Themes: one layout in four of the twelve presets, plus the Appearance screen
- `04-apps.html`: Apps: CHOSEN = A, featured top app + list (controls: see 04b)
- `04b-apps-controls.html`: Apps controls: CHOSEN = 1, search + Filters button with removable chips
- `05-app-detail.html`: App detail: CHOSEN = A identity first, plus B's selected-bar bubble
- `06-history.html`: History: CHOSEN = B, number-led
- `07-plans.html`: Plans: bento grid; front card = most urgent plan with a pin option
- `08-plan-editor.html`: Plan editor: CHOSEN = B (guided steps) to create, A (sectioned form) to edit
- `09-mid-cycle.html`: Plan that starts mid-cycle: three choices
- `10-settings.html`: Settings: grouped, Appearance on its own screen
- `11-widgets.html`: Widgets: four-widget family and states
- `12-dialogs-notification-licences.html`: Navbar (superseded by 13), dialogs, live notification, licences
- `13-navbar.html`: Floating navbar: CHOSEN = 2, three equal slots (+ round button on Plans)
- `14-palettes.html`: Palette checkpoint: 12 themes in dark and light with the contrast numbers after our rules (provisional until the user approves)

These are throwaway HTML sketches, not production code. Colours, shapes and copy are the reference; the spec is `docs/superpowers/specs/2026-10-17-expressive-redesign-design.md`.
