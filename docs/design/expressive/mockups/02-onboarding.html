More soul, more taps. A big shape illustration per step and a morphing page indicator (the active dot stretches into a pill). Four short pages (welcome, usage access, notifications, plan), each with its own Skip. It is the more playful one, but it adds steps: Google's own research warns that changing familiar patterns costs usability, so I would only choose this if first-run delight matters more to you than speed.

Permissions, order and copy stay the app's real ones. Which one is closer? Mixing is fine, for example option 1's headline and shapes with option 2's big Continue.
