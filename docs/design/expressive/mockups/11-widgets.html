How this would be built (and the honest limits)

  • Font: Glance text cannot use a variable font's width and weight axes. The tall condensed numbers would be drawn into a small image with the app's Roboto Flex (with a spoken description), recoloured per theme. Everything else stays real text.
  • Shapes: cookie, burst and the corner-mixed backgrounds are vector drawables behind the content. The wavy ring and the chart bars are drawn images (they need the exact percentage).
  • Themes: the widgets read your chosen theme and mode from the app, so Catppuccin or Gruvbox appear on the home screen too. If you pick wallpaper colours, they use the system's own colours instead.
  • App icons: the top apps use each app's real icon in these shapes (bitmaps kept small to stay under the widget memory limit).
  • Taps: each part opens the right screen: number to Home, ring to Plans, an app icon to that app's detail, forecast or speed to Home.
  • Freshness: widgets cannot tick live. They refresh when the app measures (about every minute while it runs), and show the time of the last update when offline.
  • Picker preview: today the widget picker shows a blank tile. Each widget gets a real generated preview in the picker (Android 15+) and a static one before that.
  • Resizing: each widget switches layout at set sizes (for example Bento at 4×1 becomes a single strip).
